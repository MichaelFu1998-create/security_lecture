Prompt Injection

Section 4 · the "injection" bug for AI agents
{% include "_toggle.html" %}

// what is it?

An AI agent reads untrusted content (here, a support ticket). If that content is fed into the same channel as its instructions, an attacker can hide commands in it — the same class of bug as SQL injection and XSS, one layer up.

// the fix

Keep untrusted content out of the instruction channel: separate data from instructions, constrain tools with allow-lists, filter outputs, and require human approval for sensitive actions.
