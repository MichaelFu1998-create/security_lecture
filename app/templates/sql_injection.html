// what is it?

SQL injection happens when user input is concatenated straight into a SQL query. The attacker's text stops being data and becomes part of the command, letting them rewrite what the query does — here, logging in without a valid password.

// the fix

Use parameterized queries (prepared statements) so input is always data, never code — and store hashed passwords. Flip the toggle to secure and try the payload again.
