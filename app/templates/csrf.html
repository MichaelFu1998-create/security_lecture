// what is it?

Your browser sends your session cookie with every request to a site — even requests triggered by a different site. If a state-changing action isn't protected by a secret token, a malicious page can perform it as you.

// the fix

Require a per-session CSRF token on every state-changing request, use SameSite cookies, and never change state on a GET.
