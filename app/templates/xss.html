// what is it?

A comment is stored and later shown to other users. If the app renders it as raw HTML, an attacker's <script> runs in every visitor's browser — and can steal their session cookie.

// under the hood

{% if mode == 'vuln' %} 
{% raw %}{{ comment.body|safe }}{% endraw %}   # raw render — the <script> executes
Set-Cookie: vl_demo_session=…            # no HttpOnly → document.cookie can read it
The payload reads document.cookie and beacons it to the attacker's server.
{% else %} 
{% raw %}{{ comment.body }}{% endraw %}        # auto-escaped — the script shows as text
Set-Cookie: vl_demo_session=…; HttpOnly  # JavaScript cannot read it
{% endif %}

// the fix

Escape everything you render (most engines do by default — don't disable it), add a Content-Security-Policy, and set HttpOnly on session cookies so JavaScript can't read them.
